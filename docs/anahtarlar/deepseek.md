# DeepSeek API anahtarı nasıl alınır?

DeepSeek çok ucuzdur ama **küçük bir bakiye yüklemek** gerekir. Fiyatlar değişebilir; sayfasından bak.

## Adımlar

1. Tarayıcıda **platform.deepseek.com** adresini aç.
2. Hesabınla **giriş yap** (yoksa oluştur).
3. Soldaki menüden **API keys** bölümüne gir.
4. **Create new API key** düğmesine bas.
5. Çıkan anahtarı **kopyala**. Bir daha gösterilmez.
6. **Top up** (bakiye yükle) bölümünden küçük bir tutar yükle.
7. AltYazıKöprüsü panelinde **DeepSeek**'i seç, anahtarı yapıştır, **Kaydet ve dene**'ye bas.

> 📷 Resim: (sonra eklenecek) DeepSeek platformunda "API keys" sayfası.

## Anahtar nerede saklanır?

Anahtarı panele yapıştırdığında **bilgisayarının şifreli kasasına** (Windows Kimlik Bilgisi Yöneticisi / macOS Anahtar Zinciri) yazılır. Hiçbir dosyaya düz yazı olarak yazılmaz, günlüklere girmez ve **DeepSeek** hizmeti dışında hiçbir yere gönderilmez.

> ⚠️ Anahtarını kimseyle paylaşma. Sızdığını düşünürsen sitesinden silip yenisini oluştur.
