# DeepL API anahtarı nasıl alınır?

DeepL **isteğe bağlıdır**. Ücretsiz plan ("API Free") aylık sınırlıdır; sınırlar ve fiyatlar değişebilir, DeepL'in sayfasına bak.

## Adımlar

1. Tarayıcıda DeepL'in sitesinde **DeepL API** sayfasını aç.
2. **API Free** hesabı için kaydol (koşullar için sayfasına bak).
3. Giriş yapıp **Hesap** sayfasına gir.
4. **API Keys** bölümünden anahtarı **kopyala**.
5. AltYazıKöprüsü panelinde **DeepL**'i seç, anahtarı yapıştır, **Kaydet ve dene**'ye bas.

> 📷 Resim: (sonra eklenecek) DeepL hesap sayfasında "API Keys" bölümü.

## Anahtar nerede saklanır?

Anahtarı panele yapıştırdığında **bilgisayarının şifreli kasasına** (Windows Kimlik Bilgisi Yöneticisi / macOS Anahtar Zinciri) yazılır. Hiçbir dosyaya düz yazı olarak yazılmaz, günlüklere girmez ve **DeepL** hizmeti dışında hiçbir yere gönderilmez.

> ⚠️ Anahtarını kimseyle paylaşma. Sızdığını düşünürsen sitesinden silip yenisini oluştur.
