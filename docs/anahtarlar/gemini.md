# Gemini API anahtarı nasıl alınır?

Google'ın Gemini'si için **ücretsiz kullanım hakkı** vardır ve başlamak için iyi bir seçimdir. Ücretsiz hakkın **sınırları vardır ve zamanla değişir**; güncel bilgi için Google'ın sayfasına bak. Sınır dolarsa program yedek motora geçer.

## Adımlar

1. Tarayıcıda **aistudio.google.com** adresini aç.
2. **Google hesabınla giriş yap**.
3. **Get API key** (API anahtarı al) düğmesine bas.
4. **Create API key** düğmesine bas.
5. Çıkan anahtarı **kopyala**.
6. AltYazıKöprüsü panelinde **Gemini**'yi seç, anahtarı yapıştır, **Kaydet ve dene**'ye bas.

> 📷 Resim: (sonra eklenecek) Google AI Studio'da "Get API key" düğmesi.

Ücretli plana geçmek zorunda değilsin. Fiyatlar değişebilir; sayfasından bak.

## Anahtar nerede saklanır?

Anahtarı panele yapıştırdığında **bilgisayarının şifreli kasasına** (Windows Kimlik Bilgisi Yöneticisi / macOS Anahtar Zinciri) yazılır. Hiçbir dosyaya düz yazı olarak yazılmaz, günlüklere girmez ve **Google** hizmeti dışında hiçbir yere gönderilmez.

> ⚠️ Anahtarını kimseyle paylaşma. Sızdığını düşünürsen sitesinden silip yenisini oluştur.
