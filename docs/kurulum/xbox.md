# Xbox

> ⏳ Durum: test bekliyor.

1. Bilgisayarda **Xbox** uygulamasını aç.
2. Konsolunu **Uzaktan oynatma** ile bağla (konsolda uzaktan özellikler açık olmalı).
3. Oyunu başlat.
4. **AltYazıKöprüsü** panelinde **Xbox**'u seç.
5. Listeden **Xbox** penceresini seç.
6. **Başlat**'a bas.

> 📷 Resim: (sonra eklenecek) Xbox uygulaması penceresi ve panelde seçimi.

Pencere gizlenirse görüntü alınamayabilir; küçültme. Olmazsa tüm ekranı seç.

Konsol bilgisayara kartla bağlıysa [yakalama kartı](yakalama-karti.md) rehberine bak.
