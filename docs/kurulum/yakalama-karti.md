# Yakalama kartı / OBS

> ⏳ Durum: test bekliyor.

Yakalama kartı, konsolun görüntüsünü bilgisayara getirir.

1. Konsolu karta, kartı bilgisayara bağla.
2. Kartın görüntüsünü gösteren bir program aç (OBS veya kartın kendi programı).
3. Görüntünün penceresini **küçültmeden** açık bırak.
4. **AltYazıKöprüsü** panelinde **Yakalama kartı / OBS**'i seç.
5. Listeden o programın penceresini (ya da tüm ekranı) seç.
6. **Başlat**'a bas.

> 📷 Resim: (sonra eklenecek) OBS önizleme penceresi ve panelde seçimi.

Yazıyı OBS içinde oyunun üstünde göstermek için [OBS bölümüne](tv-tarayici.md#obs-ile-oyunun-üstüne-bindirme) bak.
