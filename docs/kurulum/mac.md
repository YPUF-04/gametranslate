# macOS (sonra / beta)

macOS desteği planlıdır ama **henüz hazır değildir ve denenmemiştir**. Ekrandaki yazıyı okumak için macOS'un kendi okuyucusu (`ocrmac`) kullanılacak.

Merak edenler kaynaktan deneyebilir (Python 3.11+):

1. Terminal'i aç.
2. `pip install -e .[ocr-mac]` yaz.
3. `python -m kopru` yaz.
4. Ekran kaydı izni istenirse **Sistem Ayarları → Gizlilik ve Güvenlik → Ekran Kaydı** bölümünden izin ver.

> 📷 Resim: (sonra eklenecek) macOS ekran kaydı izni penceresi.
