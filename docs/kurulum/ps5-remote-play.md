# PS5 (PS Remote Play ile)

PS5'in görüntüsünü bilgisayara getiriyoruz; program da oradan okuyor.

> ⏳ Durum: test bekliyor (gerçek PS5 ile henüz denenmedi).

1. Bilgisayarına **PS Remote Play** uygulamasını kur (Sony'nin sitesinden).
2. PS5'te **Ayarlar → Sistem → Uzaktan Oynatma**'da uzaktan oynatmayı aç.
3. Bilgisayarda PS Remote Play'i aç ve PS5'ine bağlan.
4. Oyunu başlat.
5. **AltYazıKöprüsü** panelinde **PS5**'i seç.
6. "Hangi ekranı çevirelim?" listesinden **PS Remote Play** penceresini seç.
7. **Başlat**'a bas.

> 📷 Resim: (sonra eklenecek) Panelde listeden PS Remote Play penceresinin seçilmesi.

## İpuçları

- PS Remote Play penceresini **küçültme**; pencere gizliyken görüntü alınamayabilir.
- Pencereyi tam ekran yaparsan listeden **Ekran 1**'i seçmen gerekebilir.
- TV'de gösterim için [LG kurulumu](lg-webos.md) veya [tarayıcı](tv-tarayici.md).
- Remote Play ile oyun bilgisayarın ekranında görünür. Çeviriyi TV'de görmek için TV'yi bilgisayara ikinci ekran olarak bağlayıp Remote Play penceresini oraya taşıyabilirsin.
